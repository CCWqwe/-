# 超市销售数据分析与业务洞察

## 项目简介
本项目对某超市 9994 条订单数据进行清洗与探索性分析，涵盖品类、地区、折扣三大维度，识别亏损品类并定位折扣临界点，输出可视化报告与业务优化建议。

## 数据集
- 数据来源：SampleSuperstore.csv
- 数据量：9994 条订单记录
- 主要字段：订单ID、销售额、利润、折扣、数量、品类、子品类、地区等

## 分析维度
1. **品类分析**：各大类与子品类的销售额、利润对比，识别亏损子品类
2. **地区分析**：四大区域销售贡献与利润率分布
3. **折扣分析**：折扣率与利润率关系，定位利润由正转负的折扣临界点

## 使用工具
- Python 3.x
- Pandas（数据处理）
- NumPy（数值计算）
- Matplotlib / Seaborn（可视化）

## 核心结论
1. 识别出 3 个亏损子品类，高折扣为核心亏损原因
2. 西部地区销售额占比最高（约 32%），南部地区盈利能力最强
3. 折扣率超过某临界点后利润率转为负值，建议控制折扣力度上限
4. 输出 3 条业务优化建议，包含调整折扣策略、优化亏损品类定价、资源向高潜力地区倾斜
